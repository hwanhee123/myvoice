무료 플랜으로 되는 것과 안 되는 것
✅ 기본 제공 목소리로 텍스트 읽기 — 매달 10,000자 무료, 카드 등록 불필요
❌ 내 목소리 복제는 무료 플랜에서 안 됩니다. ElevenLabs가 Starter 플랜(월 $5)부터 제공하는 기능입니다.
일단 무료로 가입해서 읽어주기부터 써보고, 내 목소리가 필요하면 그때 결정하세요.
  1. 무료 가입하기
    구글 계정으로 가입하면 가장 빠릅니다. 이메일로 가입하면 인증 메일을 한 번 확인해야 합니다.
    elevenlabs.io 가입하러 가기 ↗
  2. 요금제는 건드리지 않습니다
    가입하면 자동으로 무료(Free) 플랜입니다. 유료 안내가 보여도 그냥 닫으세요.
  3. API 키 만들기
    아래 버튼으로 키 관리 페이지에 들어가서 Create API Key를 누릅니다. 이름은 아무거나(예: myvoice) 넣고, 나머지 설정은 기본값 그대로 두고 만들면 됩니다.
    API 키 만들러 가기 ↗
  4. sk_로 시작하는 키를 복사해서 아래에 붙여넣기
    ⚠️ 키는 만든 직후 한 번만 보입니다. 창을 닫으면 다시 볼 수 없고 새로 만들어야 하니, 뜨자마자 복사하세요.
🔒 입력한 키는 이 브라우저에만 저장되고, ElevenLabs 외의 어디로도 전송되지 않습니다. 이 페이지에는 키를 받아갈 서버가 아예 없습니다. 다른 사람 컴퓨터에서 썼다면 다 쓰고 나서 아래 "키 지우기"를 누르세요.

가입 전에 화면과 사용법을 미리 볼 수 있습니다.
